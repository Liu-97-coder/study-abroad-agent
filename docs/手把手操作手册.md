## 1. 一次性准备（约 15 分钟）

### 1.1 验证 Python

按 `Win` 键，输入 `powershell`，回车打开终端，粘贴：

```powershell
python --version
```

**看到** `Python 3.12.x` → 过关。
**如果提示"不是内部或外部命令"** → Python 没装或没勾 PATH，重装并勾选 `Add python.exe to PATH`，然后**关掉终端重开**。

### 1.2 进入项目目录

```powershell
cd "C:\Users\25045\Documents\deepseek-harness\default-workspace\study-abroad-agent"
dir
```

**看到** `ai_agent_core`、`scripts`、`README.md` 这些 → 位置对了。

> 小技巧：在文件资源管理器里打开项目文件夹，地址栏输入 `powershell` 回车，会直接在当前目录打开终端。

### 1.3 用 VS Code 打开项目

```powershell
code .
```

**看到** 左侧出现文件树（`ai_agent_core`、`data`、`docs`、`scripts`）→ 成功。
如果 `code` 命令不存在：VS Code 里按 `Ctrl+Shift+P`，输入 `Shell Command: Install 'code' command in PATH`，执行后再试。

### 1.4 选择 Python 解释器（关键一步）

VS Code 里按 `Ctrl+Shift+P` → 输入 `Python: Select Interpreter` → 回车 → 选择：

```
.\venv\Scripts\python.exe
```

（显示为 `Python 3.12.x ('.venv')`）

**为什么要做**：不选的话 VS Code 会用系统 Python，跑起来会报"找不到 fastapi"。

### 1.5 一键准备环境

在 VS Code 里按 `` Ctrl+` `` 打开集成终端（或继续用刚才的 PowerShell），粘贴：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup.ps1
```

**它做了什么**（6 步，每步都有 `[OK]`）：

1. 检查 Python 版本
2. 建虚拟环境 `.venv`
3. 装依赖（fastapi / pydantic / langgraph …）
4. 生成 `.env`（默认 mock 模式，不花钱）
5. 灌知识库（26 所院校 + 签证政策 + 文书素材 + 合规词库）
6. 跑端到端自测

**成功的标志**：最后出现

```
环境就绪！下一步：
   powershell -ExecutionPolicy Bypass -File scripts\dev.ps1
```

并且上面有 `【断言】全部通过 ✅`。

> **为什么命令前面要加 `-ExecutionPolicy Bypass`**：Windows 默认禁止运行 .ps1 脚本。
> 这一串只是"这一次允许运行"，不改系统设置。

### 1.6 如果第 3 步装依赖卡住

国内网络常见，换清华镜像重跑：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup.ps1 -Mirror https://pypi.tuna.tsinghua.edu.cn/simple
```

| 操作面 | 用来做什么 | 什么时候用 |
| --- | --- | --- |
| **终端命令** | 跑脚本、启动服务、看报错 | 每天 |

### 2.1 终端必备 5 个操作

```powershell
cd 路径            # 进入目录（路径有空格要加引号）
dir                # 看当前目录有什么
Ctrl + C           # 停止正在跑的服务
↑ / ↓              # 翻历史命令（不用重新敲）
cls                # 清屏
```

### 2.2 启动服务（每天第一件事）

```powershell
powershell -ExecutionPolicy Bypass -File scripts\dev.ps1
```

**看到**：

```
服务地址： http://127.0.0.1:8000
接口文档： http://127.0.0.1:8000/docs
INFO:     Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
INFO:     Application startup complete.
```

→ 打开浏览器访问 <http://127.0.0.1:8000/docs>，能看到一长串接口列表就算通了。

> **这个窗口不要关**。它就是这个系统的"服务器"，关了接口就停了（**数据不会丢**，见下面）。
> 要敲别的命令？再开一个终端窗口。
>
> 端口被占用时脚本会**自动往后换一个**（8000→8001→…），并打印一行黄色提示。
> **一切以窗口里打印的「服务地址」为准**，改 `.http` 文件顶部的 `@base` 或浏览器地址即可。

**关掉终端会怎样**：服务停止，但没有任何数据丢失 ——
客户档案在 `runtime/crm.db`，知识库索引在 `runtime/rag/*.json`，日志在 `logs/`。
重新双击 **`启动服务.bat`**（或再跑一次 `dev.ps1`）就恢复了，之前跑过的客户和待办都还在。

### 2.6 用 `.http` 文件批量调（会点鼠标的话看这里）

VS Code 里打开 `docs/api-examples.http`，会看到 20 个请求，每个上方有灰色的 `Send Request`：

- 点第 1 个 `GET /health` 的 `Send Request` → 右侧出现 `{"status": "ok", ...}`
- 点第 3 个选校匹配 → 右侧出现三档清单
- 点第 6 个"违规话术" → 观察返回里 `safety_blocked: true`

**找不到那个灰色小字？** 有三个等价入口：

| 入口 | 怎么做 |
| --- | --- |
| 快捷键 | 光标放在请求里任意位置，按 `Ctrl+Alt+R` |
| 右键菜单 | 在请求块上右键 → **Send Request** |
| 命令面板 | `Ctrl+Shift+P` → 输入 `REST Client: Send Request` |

**怎么改参数**：这个文件**顶部有 4 个变量**，改它们，下面 20 个请求全部跟着变：

```
@base = http://127.0.0.1:8000      ← 换端口时改这里
@customerId = demo-001             ← 换客户编号（换个名字就是另一个客户，数据分开存）
@chat = 学生李同学，南京理工大学……  ← 学生背景，选校/报告/纪要都读这段
@question = 你们能不能保录前 50？    ← 话术测试用的客户提问
```

改完 `Ctrl+S` 保存 → 点 `Send Request`，**不用重启服务**（改的是请求内容，不是代码）。

**为什么推荐**：改一次参数、点一下鼠标，比在 `/docs` 里翻找快得多，而且这些请求可以存进 Git 当"接口用例"。

## 5. 排查手册（按症状查）

| 症状 | 原因 | 怎么修 |
| --- | --- | --- |
| `python` 不是命令 | 没装或没勾 PATH | 重装 Python，勾 Add to PATH，重开终端 |
| `无法加载文件 ... 因为在此系统上禁止运行脚本` | 执行策略 | 命令前加 `powershell -ExecutionPolicy Bypass -File` |
| `scripts\setup.ps1 : 缺少 }` 之类解析错误 | 脚本被存成了无 BOM 的 UTF-8，PS 5.1 按 ANSI 读 | 用 VS Code 另存为 **UTF-8 with BOM** |
| `ModuleNotFoundError: fastapi` | 用了系统 Python，不是 `.venv` | VS Code `Ctrl+Shift+P` → Select Interpreter → `.venv` |
| `[Errno 10048]` 端口占用 | 8000 被别的程序占了 | `dev.ps1` 会自动换端口，看窗口打印的地址；也可手动 `-Port 9000` |
| 终端关了，服务没了 | 正常现象，服务跟窗口同生共死 | 双击 `启动服务.bat` 重开；数据都在 |
| 控制台一片空白 / 提示"登录已过期" | Token 过期（默认 8 小时）或 `AUTH_SECRET` 改过 | 刷新页面重新登录 |
| 一直转圈、接口 401 | 没登录就调了接口 | 先登录；脚本用 `api_smoke.py`（会自己登录） |
| 学生端打开 404 | 链接里的 `k=` 不对，或客户被重置过 | 回控制台重新点「学生端链接」 |
| 上传图片报"需要 rapidocr" | 没装图片 OCR 依赖 | `pip install rapidocr-onnxruntime pillow` |
| 图片识别不准 | 拍歪了/反光/字太小 | 重拍：正对、光线均匀、占满画面；或改贴文字 |
| 切 Milvus 后报 `Illegal uri` | `.env` 里用了 `MILVUS_URI` 这个名字 | 改成 `MILVUS_SERVER_URI` / `MILVUS_LOCAL_PATH` |
| 切 Milvus 后检索报 `collection released` | 服务/脚本跨进程打开同一个 Lite 库 | 先 `load_collection`（已内置），且别两个进程同时写 |
| `/docs` 打不开 | 服务没起或已退出 | 看启动窗口有没有红色报错；`Ctrl+C` 重跑 |
| 接口返回 `{"detail":"请求过于频繁"}` | 触发了限流（20 次/分钟） | 等 60 秒，或改 `api/deps.py` 的 `capacity` |
| 中文显示成 `锟斤拷` / `????` | 控制台编码 | 用 `scripts\*.ps1`（已设 UTF-8）；或 `chcp 65001` |
| `知识库未命中` | 没灌库 | 跑 `ingest_seed.py` |
| `知识库为空` 启动告警 | 同上 | 同上 |
| 改代码没生效 | 没用 `--reload` 或改的是 `.env` | `.env` 改了必须重启服务 |
| `AssertionError` / 断言 FAIL | 你改的规则破坏了预期 | 看 smoke_test 输出里对应段落，逐字段比对 |
| 调试时断点不生效 | 选错了配置 / 解释了别的文件 | 按 `Ctrl+Shift+D` 选 `① 端到端自测` |

**万能三步**：

```powershell
# 1. 确认解释器
.\.venv\Scripts\python.exe --version

# 2. 确认依赖
.\.venv\Scripts\python.exe -c "import fastapi, langgraph; print('ok')"

# 3. 重跑端到端
.\.venv\Scripts\python.exe scripts\smoke_test.py
```
